# NextGen-Navigator-Career-counseling-chatbot
A fully interactive, GUI career counseling system that guides students through a career quiz, AI-powered counseling session, and generates a personalized career roadmap with country-specific guidance.
# Requirements
- Python 3.8+
- API key 
- Internet connection
# Features
- Career Quiz | 20 questions → percentage scores across 12 career fields |
- AI Counseling | Multi-turn chat with Claude AI, personalized to quiz results |
- Country Guidance | Tailored advice for Pakistan, Middle East, Europe, North America, Australia |
- Career Roadmap | 4-phase roadmap with universities, certifications, salaries, and job targets |
- Saved Output | Roadmap saved as a ".txt" file for the student |
